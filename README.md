# Zynlo CRM

Shared call-centre workspace for Zynlo: agents, customers, clients, call log, messages, and bi-weekly client reports.

## Latest

- Quick Log (phone + notes + call type + QA)
- Call log includes customer phone
- Calls today split into inbound / outbound
- Calls by day chart
- Agent and dashboard QA scores from rated call logs
- Data saved to the shared Firebase workspace

## Run

```bash
npm install
npm run dev
```

Preview binds to port 8080.
